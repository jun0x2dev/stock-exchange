# bot

## 정의

참고 시세를 따라 호가를 내고(`maker`) 가끔 거래하는(`taker`) 봇. 혼자 써도 사고팔 상대가 있게 한다. 일반 사용자와 같은 계좌, 검증, 예약, 원장을 거친다.

## 주요 상태/흐름

```
exchange-feed(모의 시세) ─▶ quote 토픽 ─▶ QuoteBotRunner ─▶ 주문·취소 명령 ─▶ 엔진
```

- 2초마다 시세 양쪽에 한 호가씩 떨어진 3단계를 맞춘다. 그대로인 호가는 두고, 절반 넘게 체결된 호가는 새로 낸다.
- 취소를 먼저 커밋하고 새 주문을 커밋한다. 엔진이 취소부터 처리하므로 봇끼리 체결되지 않고, 새 주문이 거부돼도 옛 호가는 거둬진다.
- 5초 넘게 새 시세가 없거나 처음부터 없으면 호가를 모두 거둔다. 경과 시간은 뒤로 갈 수 있는 벽시계 대신 `nanoTime`으로 잰다.
- `exchange.bot.enabled`로 켠다. Docker로 전체를 띄우면 켜지고, 개발 모드에서는 꺼져 있다.

## 관련 이벤트 (Kafka 토픽)

`quote` (키: 종목, 1시간 보존). 실제 시세 수집기를 붙일 때도 이 토픽만 채우면 된다.

## 한계

- 시세가 움직일 때마다 주문과 원장이 늘어난다. 6종목에서 30초에 주문 118건이었다.
- 체험용 계좌의 돈과 주식이 떨어지면 그 종목의 호가가 줄어든다.
