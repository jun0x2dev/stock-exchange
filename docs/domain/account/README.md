# account

## 정의

계좌 잔고, 보유 종목, 모의 입금과 주식 입고.

## 주요 상태/흐름

- 예약과 입금은 조건부 UPDATE, 체결 반영은 행 잠금 후 엔티티 변경으로 처리한다.
- 입금·입고는 `deposit` 테이블의 멱등키로 중복을 막고, 상대 계정은 `EXTERNAL`이다.
- 입고한 주식의 매입 원가는 기준가로 본다(프로젝트 정책).
- 모든 접근은 `AccountAccess`로 소유자를 확인하며, 남의 계좌는 404로 존재를 숨긴다.

- 승인된 정정은 조건부 UPDATE로 뺀다. 이미 썼거나 주문에 묶인 만큼은 되돌리지 못한다. 주식의 원가는 매도와 같이 평균으로 줄인다(프로젝트 정책).
