# matching

## 정의

종목을 워커 스레드에 배정해 엔진을 돌린다. 같은 종목은 항상 같은 스레드가 처리한다.

## 주요 상태/흐름

1. 주문·취소가 커밋되면 종목에 신호를 보낸다. 신호는 종목마다 하나만 대기한다.
2. 워커가 DB에서 접수 대기 주문과 취소 요청을 발생 시각 순으로 읽는다.
3. 명령을 최대 20개씩 매칭하고 결과를 한 트랜잭션으로 반영한 뒤 조회용 호가창을 바꾼다([이유](../../trade-offs/2026-11-24-batch-settlement.md)).

- 기동: 모든 종목에 신호를 보낸다. 호가창을 `engine_seq` 순으로 복원하고 밀린 명령을 이어서 처리한다.
- 실패: 호가창을 버리고 DB에서 다시 만든 뒤 하나씩 처리한다. 연속 3번 실패하면 명령을 건너뛰지 않고 종목을 `HALTED`로 바꾼다.
- 정지 해제: 원인을 없애고 종목 상태를 `TRADABLE`로 바꾼 뒤 재시작한다. 운영자 화면은 3단계다.
