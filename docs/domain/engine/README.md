# engine

## 정의

한 종목의 호가창과 매칭 규칙. DB와 Spring에 의존하지 않는 순수 Java이며 시계와 난수를 쓰지 않는다.

## 주요 상태/흐름

- `place` → `Accepted` 다음에 `Traded`가 0개 이상, 자전거래면 `Canceled`로 끝난다.
- `cancel` → `Canceled`, 이미 빠진 주문이면 이벤트가 없다.
- 모든 이벤트에 종목별 순번을 붙이며, 접수 순번이 시간 우선의 기준이 된다.

## 관련 불변식

- 같은 입력에는 같은 이벤트가 나온다. 매수 호가는 항상 매도 호가보다 낮다.
- 무작위 2만 건을 시드 5개로 검증한다(`OrderBookTest`).
