# outbox

## 정의

엔진에 보낼 주문·취소 명령을 주문과 같은 트랜잭션에서 저장하고 Kafka로 옮긴다.

## 주요 상태/흐름

1. 주문 접수와 취소 요청이 `outbox`에 명령을 함께 저장한다. 커밋되지 않으면 명령도 없다.
2. 발행기가 커밋 직후(늦어도 0.5초 안에) 명령 번호 순으로 최대 200건을 읽어 Kafka 트랜잭션 하나로 보낸다.
3. 보낸 명령에 `published_at`을 남긴다. 이 표시만은 디스크 동기화를 기다리지 않는다. 잃어도 다시 보내고 엔진이 버린다.

- 묶음을 나눠 보내면 일부만 나간 뒤 다시 보낼 때 같은 주문의 취소가 접수보다 먼저 갈 수 있어, 전부 나가거나 전부 취소되게 한다.
- 발행기가 여러 개 떠도 advisory lock으로 하나만 보낸다.

## 관련 이벤트 (Kafka 토픽)

`order-command` (키: 종목, 보존 기간 없음)
