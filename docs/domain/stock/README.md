# stock

## 정의

종목, 거래 상태, 호가 단위와 가격제한폭.

## 주요 상태/흐름

- `TRADABLE` ↔ `HALTED`. 정지된 종목은 주문을 받지 않는다.
- 호가 단위와 상·하한가 계산 순서는 [KRX 호가 단위](https://global.krx.co.kr/contents/GLB/06/0602/0602010201/GLB0602010201T3.jsp), [KRX 가격제한폭](https://global.krx.co.kr/contents/GLB/06/0602/0602010201/GLB0602010201T5.jsp)과 대조했다(2026-11-24).
- 마지막 단계의 반올림 방향은 자료에 없어 상한가는 내림, 하한가는 올림으로 정했다(프로젝트 정책).
- 종목은 모두 가상이며 실제 시세가 아니다.
