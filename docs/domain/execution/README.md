# execution

## 정의

엔진 이벤트를 주문, 잔고, 보유 종목, 원장에 반영하고 체결을 조회한다.

## 주요 상태/흐름

- 잠금 순서: 계좌(ID 순) → 보유 종목(계좌 ID 순) → 주문(ID 순).
- 엔진 순번이 `last_event_seq` 다음부터 빈틈없이 이어져야 반영한다. 어긋나면 실패시키고 호가창을 다시 만든다.
- 1단계는 엔진과 DB가 한 프로세스라 재전송이 없으므로, 이미 반영한 순번도 무시하지 않고 오류로 본다. Kafka를 도입하는 2단계에서 중복 무시로 바꾼다.
