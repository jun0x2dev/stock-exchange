# realtime

## 정의

호가·체결과 내 주문의 변화를 화면에 WebSocket으로 보낸다.

## 주요 상태/흐름

- 결과 반영이 **커밋된 뒤** 종목과 관련 사용자를 모아 0.2초에 한 번 보낸다. 롤백된 내용은 나가지 않는다.
- `MARKET`: 호가창과 최근 체결. 계좌나 주문 ID가 들어 있지 않다.
- `ACCOUNT`: 내 주문이나 잔고가 바뀌었다는 알림. 내용은 화면이 권한 검사를 거치는 API로 다시 조회한다.
- 연결이 끊기면 화면이 원래 주기(1~2초)로 조회하고, 간격을 늘려 가며 다시 연결한다.

## 접근 통제

- 로그인한 세션만, 같은 출처에서만 연결할 수 있다.
- 로그아웃하거나 세션이 끝나면 연결을 끊는다. HTTP 세션과 달리 WebSocket은 저절로 끊기지 않는다.
- 사용자마다 5개까지, 화면에서 오는 메시지는 받지 않는다. 느린 화면은 밀린 양이 커지면 끊는다.
