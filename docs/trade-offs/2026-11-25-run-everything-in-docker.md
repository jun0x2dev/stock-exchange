# 전체를 Docker로 띄우는 방법

## 선택지

1. DB와 Kafka만 Docker로, 나머지는 직접 실행한다.
2. 전부 Docker로만 실행한다.
3. 둘 다 지원한다. 평소에는 1번, `--profile app`을 붙이면 전부 띄운다.

## 선택

3번. 화면은 core의 jar에 넣어 같은 출처(8080)로 서비스한다.

## 이유

- 개발 중에는 코드를 고칠 때마다 이미지를 다시 만드는 시간이 크다. 저장소를 내려받은 사람에게는 JDK와 Node 설치가 부담이다.
- 화면용 웹 서버를 따로 두면 컨테이너가 늘고 출처가 갈라진다.
- 기반 이미지는 digest로 고정하고, 빌드에 보내는 파일을 `.dockerignore`에서 허용 목록으로 제한한다. `.env`와 로컬 문서가 이미지에 들어가지 않는 것을 확인했다.
- 컨테이너는 일반 사용자로 실행하고, 포트는 `127.0.0.1`에만 연다.
- 감수한 점: 기반 이미지의 보안 수정을 받으려면 digest를 직접 갱신해야 한다.
