# Kafka 하위 라이브러리의 취약점으로 CI 실패

## 증상

엔진을 분리하며 `kafka-clients`를 추가하자 CI의 Trivy가 HIGH 3건으로 실패했다. `lz4-java` 1.11.2(CVE-2026-106451), `snappy-java` 1.1.10.7(CVE-2026-108106, CVE-2026-93451).

## 원인

`kafka-clients` 4.2.2가 가져오는 간접 의존성이다. 직접 쓰지 않아도 배포 파일에 들어간다. lockfile에 간접 의존성까지 적어 두어 검사에 걸렸다.

## 해결

- 수정된 버전(1.11.4, 1.1.10.9)으로 올려 고정했다. Spring Boot가 더 높은 버전을 쓰면 지운다.
- 푸시하기 전에 같은 검사를 로컬에서 돌리지 않은 것이 원인 중 하나다. CI와 같은 명령을 로컬에서도 실행할 수 있다.
